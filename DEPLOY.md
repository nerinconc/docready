# DocReady 30-Minute Zero-Cost Deployment Guide

1. **GitHub + Vercel (Free Tier):** Push this folder to a private GitHub repo and import it in Vercel (vercel.com).
2. **Supabase (Free Tier — 500MB DB, 1GB Storage):** Create a project at supabase.com, paste `supabase-schema.sql` into the SQL Editor, and create a private Storage bucket named `client-docs`.
3. **Resend (Free Tier — 3,000 emails/mo):** Create an API key at resend.com and add `RESEND_API_KEY` in Vercel Project Settings -> Environment Variables.
4. **Checkout (Lemon Squeezy or Gumroad — $0/mo, transaction fee only):** Create 3 products ($79 Founding Pass, $29/mo Solo, $59/mo Firm) and link the checkout URLs on your landing page.
